# Community conduct

Be respectful, patient, and specific. Critique evidence and implementation choices rather than people. Welcome different experience levels and acknowledge uncertainty.

Harassment, discrimination, threats, doxxing, sexualized abuse, and deliberate disclosure of private data are not acceptable. Do not pressure maintainers or contributors to run unsafe code or reveal credentials.

Maintainers may edit or remove harmful content, pause discussions, or restrict participation in proportion to the behavior. Apply these expectations consistently. For a sensitive conduct concern, request a private contact channel without posting personal details publicly. Security vulnerability reports follow SECURITY.md rather than ordinary issue discussions.
